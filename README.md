# Семестр

Трекер чтения для вуза с **курсорным чтением**: страницы засчитываются, только если ты зажимаешь кнопку и реально ведёшь курсор по тексту. Так сложнее «пролистать PDF под музыку».

## Зачем

- Плохой самоконтроль и страх электронных книг
- Нужно читать ~10 страниц в день из 4 книг
- Дедлайны по предметам, темп до зачёта
- PDF-загрузка + режим, где нельзя свободно перескакивать текст

## Как работает курсор

1. Открываешь книгу → «Читать курсором»
2. Зажимаешь пробел или большую кнопку
3. Курсор медленно едет по фразам (скорость ограничена)
4. Отпустил — стоп
5. Страница засчитывается только когда курсор дошёл до конца страницы

## Запуск

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000).

## Стек

- Next.js (App Router) + TypeScript + Tailwind
- PDF.js для извлечения текста
- IndexedDB для PDF, localStorage для прогресса

## Скрипты

- `npm run dev` — разработка
- `npm run build` — сборка
- `npm run start` — прод
- `npm run lint` — линтер
