# Семестр

Трекер чтения для вуза с нормальным PDF-ридером.

## Что умеет

- Загрузка больших PDF (1000+ страниц) без парсинга всего текста
- Просмотр страница за страницей (стрелки, переход, зум)
- Дневная норма: 4 книги × 10 страниц (настраивается)
- Дедлайны, темп, стрик, недельный график
- Данные и PDF хранятся локально в браузере

## Запуск

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000).

## Как пользоваться

1. **Добавить книгу / PDF** — выбери файл
2. **Открыть PDF** — листай ← → или кнопками
3. **Сохранить и выйти** — прогресс запишется в дневной план

## Важно

Если раньше PDF «не открывался» на 1500 страницах — это потому что старая версия пыталась вытащить текст со всех страниц сразу. Сейчас считается только число страниц, а рисуется одна текущая.
