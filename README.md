# Семестр

Трекер чтения для вуза: книги с дедлайнами, дневная норма, стрик и темп до зачёта.

## Возможности

- Добавление учебников и литературы с предметом и дедлайном
- Расчёт нужных страниц в день по сроку
- Дневная норма и стрик для самоконтроля
- Быстрая запись сессий чтения
- Локальное хранение данных в браузере (localStorage)

## Запуск

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000).

## Скрипты

- `npm run dev` — разработка
- `npm run build` — сборка
- `npm run start` — прод-сервер
- `npm run lint` — линтер
